# SDK example only

README. It demonstrates the experimental extension SDK, not a real failure or
supported language. See [the official Pack](../extensions/example_language_pack.py)
and [SDK guidance](../../docs/extension-sdk.md).

the built-in Python Pack and does not load this example.
